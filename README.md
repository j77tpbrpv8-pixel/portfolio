# Leo Comaroff photography site

Files:
- index.html : the whole site (text, layout, prices). Edit text here.
- photos.js  : the list of photos and captions. Add a line here for each new photo.
- images/    : every photo. Upload new photos here.
- images/presets/ : before/after and sample photos for the Lightroom presets page.

Add a photo: upload to images/, add one line to photos.js, "Commit changes". The site updates in 1-2 minutes.
Photo tips: about 2000 px on the long edge, JPEG, under 1 MB each.
